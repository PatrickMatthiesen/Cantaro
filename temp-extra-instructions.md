# Cantaro Media Detail Page Plan

## Goal

Create a reusable media detail page for both desktop and mobile.

The page should make it easy to understand what the media is, track progress, continue watching, add it to the library, and browse deeper information without feeling crowded.

## Core Layout

The page is split into two main areas:

1. **Top media area**
2. **Bottom detail area**

## Top Media Area

The top area introduces the media and should feel cinematic.

It should include:

- Poster or cover image
- Blurred/cropped media artwork as background
- Title
- Media type
- Genre(s)
- Release year
- Runtime or average episode length
- Episode count when relevant
- Community score / stars
- Age rating when relevant
- Primary watch action
- Quick add-to-library action
- User progress summary

The progress view should be visually important and easy to use.

It should show:

- Current watch state
- Watched amount
- Total amount when known
- Percentage complete
- Next episode or next action
- User score when available
- Sync/update state when relevant

## Bottom Detail Area

The bottom area contains navigable subpages.

Recommended sections:

- Overview
- Progress
- Providers
- Related / Franchise
- Characters / Cast
- Details
- Community / Reviews

The available sections should depend on the media type and available data.

## Overview Priorities

The overview should show the most useful supporting information first:

1. Where to watch
2. Related media or franchise order
3. Main characters or cast
4. Key information
5. Community summary

## Responsive Behavior

Desktop should use the extra width for a richer layout with side-by-side cards and supporting panels.

Mobile should keep the same content hierarchy, but stack sections vertically and use horizontal scrolling where useful.

Both versions should feel like the same page, not separate designs.

## Visual Direction

Use the Cantaro visual style:

- Accent colors
- Glass-like cards
- Rounded corners
- Soft borders
- Strong hierarchy
- High readability

The page should feel like a polished media library cockpit, not a plain database entry.
